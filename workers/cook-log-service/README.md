# cook-log-service

Deployed by Cloudflare Workers Builds from this folder on main. The old MichaelWMerrill/cook-log-service repo is retired.

Build settings: root `workers/cook-log-service`, watch path `workers/cook-log-service/*`, no build command, deploy command `npx wrangler deploy`.

Docs for the data layer, the migrations and the capture UI are in the repo's top-level README ("Cook log data layer").
